# 💚 Green Lantern: Willpower Construct

A real-time, Green Lantern-inspired computer vision experience that transforms hand gestures into interactive energy constructs and superhero-style suit-up effects. 💍⚡

Built as a childhood dream brought to life through creative coding, computer vision, and AI-assisted development.

## ✨ Features

* **Real-Time Hand Tracking:** Uses OpenCV and MediaPipe to enable gesture-driven interactions.
* **Interactive Energy Constructs:** Create and control Green Lantern-inspired constructs through hand movements.
* **Emerald Visual Effects:** Glowing outlines, animated energy surfaces, and particle effects inspired by the Green Lantern universe.
* **Ring Energy System:** Construct activations consume energy, with low-battery notifications and a recharging mechanic.
* **Quick Suit-Up:** A superhero-inspired transformation experience designed around interactive gestures.
* **Custom UI/UX:** A tailored interface combining HTML, CSS, JavaScript, and Canvas-based visual effects.
* **AI-Assisted Development:** Iterative prompt engineering and AI tools helped explore implementation strategies, refine interactions, and integrate different components.

## 🛠️ Tech Stack

* **Python** — Computer vision integration
* **OpenCV** — Camera processing and visual tracking
* **MediaPipe** — Hand tracking and gesture recognition
* **HTML5, CSS3 & JavaScript** — Frontend and interaction logic
* **Canvas API** — Real-time rendering and visual effects
* **AI-Assisted Development** — Prompt engineering and iterative prototyping

## 🎯 Project Goal

Explore how computer vision, gesture recognition, and real-time graphics can transform a webcam into an interactive superhero-inspired experience.

The project focuses on combining responsive interactions, visually engaging effects, and performance-conscious implementation into a cohesive experience.

## 🚀 Current Status

An experimental, evolving project with opportunities to improve tracking accuracy, visual effects, responsiveness, and interaction design.
