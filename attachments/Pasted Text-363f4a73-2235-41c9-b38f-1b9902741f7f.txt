FINGER SELECTION

After the ring is equipped:

The INDEX FINGER selects constructs.

Do NOT make the user place the whole palm precisely over a tiny button.

Use the fingertip position.

Calculate selection using the actual DOM element bounds:

getBoundingClientRect()

Convert camera coordinates into screen coordinates correctly.

The hitboxes should be forgiving.

Add approximately:

10–20 px horizontal padding
8–16 px vertical padding

Use a short dwell:

~250–400 ms

before confirming selection.

Show a subtle progress ring/bar while hovering.

The user should immediately understand:

"My finger is currently selecting SWORD."

==================================================
SECOND ROW FIX

The second row MUST be just as easy to select as the first row.

Do NOT hardcode:

if y < somePixelValue

because that will break on different screens.

Instead:

for each construct button:

rect = button.getBoundingClientRect()

check whether:

fingerX >= rect.left - padding
fingerX <= rect.right + padding
fingerY >= rect.top - padding
fingerY <= rect.bottom + padding

This must work regardless of viewport size.
